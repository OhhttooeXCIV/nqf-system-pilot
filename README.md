# Bridge5 stakeholder pilot

Bridge5 demonstrates an evidence-led first test for an NQF Level 5 systems-support learning journey. It is intentionally a frontend-first pilot.

## What works

- Responsive learner overview for desktop, tablet and mobile.
- Four-module first-test pathway: hardware diagnostics, operating systems, networking and service-desk simulation.
- Module selection, evidence checklists and browser-local checkpoint persistence.
- Learner-to-lecturer-to-assessor-to-provider hand-off story.
- Thin `/api/pilot` manifest and non-durable acknowledgement endpoint.

## What it does not claim

This is not an accredited programme, learner management system, official ATP, QCTO submission, assessment centre, EISA platform or certification service. Production requires the exact registered qualification documents, accredited provider scope, approved assessment arrangements, POPIA controls, verified identity, role-based access, immutable audit history and approved reporting integration.

## First frontend slices

1. Evidence-led learner dashboard and local persistence.
2. Lecturer queue, feedback and intervention records.
3. Assessor evidence pack and moderation sampling.
4. Provider compliance exports and governed integrations.
5. Production identity, security, retention and interoperability.
